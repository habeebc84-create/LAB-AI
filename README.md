# LAB-AI

Collection of AI lab experiments (Day 1 - Day 5).

## Structure

- `Day1/` - Search and classic AI problems.
- `Day2/` - CSP, game AI, ML basics, Prolog DBs.
- `Day3/` - Prolog programs.
- `Day4/` - Web, regression, KNN, NN image classification, decision tree, sentiment, GA, SVM, PCA, recommender.
- `Day5/` - Chatbot, clustering, Q-learning, segmentation, Markov chain, object detection, hyperparameter tuning, Bayesian network, face detection, GA-NN.

## Run

Most programs are Python 3:

```bash
python Day1/1.1_8_Puzzle.py
```

Prolog files (`.pl`) require a Prolog interpreter (e.g. SWI-Prolog):

```bash
swipl -s Day2/2.7_Prolog_Sum_1_to_n.pl
```

## Requirements

pip install numpy scikit-learn torch torchvision opencv-python pandas
